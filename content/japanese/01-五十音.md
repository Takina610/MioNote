# 五十音图

![](./img/Snipaste_2026-08-11_10-43-33.png)

**在读 "u " 的时候，嘴巴是往里的，不是往外撅着读**
**在读 "e" 和 "o" 的时候，不要延长收尾音，而是干净利落一个音读完**


平假名和片假名都有对应的中国汉字

- 平假名：平常使用的日本本土的单词
- 片假名：主要用于外来词，如英语、法语、德语...

# 元音

![](./img/Snipaste_2026-08-11_10-51-36.png)

あ 通过汉字 "安" 来记忆，发音为 "a"

い 通过汉字 "以" 来记忆，发音为 "i"

う 联想汉字 "宇"，写法有点像数字 "5" 来记忆，发音为 "u"

え 联想汉字 "衣"，通过汉字 "诶"（发音接近）来记忆，发音为 "e"

お 联想汉字 "於"，写法有点像 "我"，通过汉字 "哦"（发音接近）来记忆，发音为 "o"

# K行音

![](./img/Snipaste_2026-08-11_14-22-41.png)

か 通过汉字 "加" 来记忆，发音为 "ka"

き 联想汉字 "幾"，通过英文单词 "key" 来记忆，写法像一个左斜的钥匙，发音为 "ki"　

く 联想汉字 "久"，< 像是哭的感觉，发音为 "ku"

け 通过汉字 "计" 来记忆，发音为 "ke"

こ 联想汉字 "己"，通过 "口" 来记忆，发音为 "ko"

# S行音

![](./img/Snipaste_2026-08-11_14-54-58.png)

さ 联想汉字 "佐"，通过 "杀" 来记忆，写法像一个右斜着的 "杀"，就是 "き" 少一笔 ，发音为 "sa"

し 联想汉字 "之"，像是弯折的"吸"管一样，写为 "shi"，读为 "xi"

す 联想汉字 "寸"，像是果汁，吸管然后有个柠檬，juice 的发言就是 "jiu su"，发音为 "su"

せ 通过汉字 "世" 来记忆，发音为 "se"

そ 联想汉字 "曾" 来记忆，写法有点像是在"嗦"面，发音为 "so"

# T行音

![](./img/Snipaste_2026-08-11_16-00-07.png)

た 通过汉字 "太" 来记忆，发音为 "ta"

ち 联想汉字 "知"，通过 "七" 来记忆，写法有点像 "6+1"，写为 "chi"，读为 "qi"

つ 联想汉字 "川"，通过 "吃" 来记忆，像是一个嘴巴在吃，写为 "tsu"，读为 "ci"

て 通过汉字 "天" 来记忆，发音为 "te"

と 联想汉字 "止"，通过 "拖" 来记忆，像是一个婴儿被拖着走，发音为 "to"

# N行音

![](./img/Snipaste_2026-08-11_16-23-16.png)

な 通过汉字 "奈" 来记忆，发音为 "na"

に 通过汉字 "仁" 来记忆，发音为 "ni"

ぬ 通过汉字 "奴" 来记忆，发音为 "nu"

ね 通过汉字 "弥"，联想记忆 "内"卷的 "内" 字，发音为 "ne"

の 通过汉字 "乃" 来记忆，"的" 字潦草版，发音为 "no"

# H行音

![](./img/Snipaste_2026-08-12_09-23-09.png)

は 联想汉字 "波"，通过 "哈" 来记忆，左半边像是沙袋，右边的人在打拳，打拳"哈"！，发音为 "ha"

ひ 像是一个人在坏笑发出的表情，"hi hi hi~"，发音为 "hi"

ふ 联想汉字 "不"，像是一个人跪倒在地上，"我服(fu)了~"，发音为 "fu"

へ 联想汉字 "部"，像是一个人"嘿嘿(he)"笑时眼睛的形状，发音为 "he"

ほ 联想汉字 "保"，通过 "嚯" 来记忆，左半边像是沙袋，右边的人戴着帽子在打拳，打拳"嚯"！，发音为 "ho"

# M行音

![](./img/Snipaste_2026-08-12_09-42-52.png)

ま 联想汉字 "末"，写法也像 "末"，"末" 的发言是 "まつ"，发音为 "ma"

み 联想汉字 "美"，写法像一个倾斜的 "m"，"i" 插在末尾，发音为 "mi"

む 联想汉字 "武"，一条蛇靠在一根木(mu)棍上，发音为 "mu"

め 联想汉字 "女"，美(mei)女，像 "ぬ" 末尾没(mei)了圈，发音为 "me"

も 联想汉字 "毛"，第一笔是先写竖笔画，发音为 "mo"

# Y行音

![](./img/Snipaste_2026-08-12_10-42-18.png)

や 联想汉字 "也"，发音为 "ya"

ゆ 联想汉字 "由"，发音为 "yu"

よ 联想汉字 "与"，第一笔是写横，发音为 "yo"

# R行音

![](./img/Snipaste_2026-08-12_10-52-13.png)

由于日本人读不了 r 音，所以 r 行都读成 l

ら 像一个人在蹲马桶，写为 "ra"，读音为 "la"

り 像是利(li)刀旁，写为 "ri"，读音为 "li"

る 像是轮椅车车轱辘(lu)转，写为 "ru"，读音为 "lu"

れ 联想汉字 "礼"，写为 "re"，读音为 "le"

ろ 像是车轱辘掉落(lo)，写为 "ro"，读音为 "lo"

# W行音

![](./img/Snipaste_2026-08-12_11-23-08.png)

わ 联想汉字 "和"，，读音为 "wa"

を 像是一个人跨进了水池，读音为 "wo"

# ん

ん 联想汉字 "恩"，像是一个人弯腰鞠躬，通过输入 "nn" 可以输出，写为 "n"，读音为 "en"
