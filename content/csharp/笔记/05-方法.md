```csharp
using System;

namespace ConsoleApp1
{
    class Person
    {
        int age;

        public void setAge(int age)
        {
            this.age = age;
        }

        public int getAge()
        {
            return age;
        }

        public int getAge2() => age;
    }

    class Program
    {
        static void Main()
        {
            Person person = new Person();
            person.setAge(18);

            Console.WriteLine($"{person.getAge()}");
        }
    }
}
```

- public int getAge2() => age; `=>` 在 C# 中称为 `goes to` 符号
  - 整个式子叫做**表达式主体**，是 C# 中的一种语法糖；前面的**字符串插值**也是一种语法糖
