```csharp
using System;

namespace ConsoleApp1
{
    class Program
    {
        static void Main()
        {
            Console.WriteLine("Hello, World!");
            Console.WriteLine("你好，世界");

            Console.Write("这是否有点...");
        }
    }
}
```

- 通常会默认引用某些库，比如 System 库就是默认引用的
- Console.WriteLine(); 就是换行的
- Console.Write(); 就是不换行的
