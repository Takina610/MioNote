```csharp
using System;

namespace ConsoleApp1
{
    class Program
    {
        static void Main()
        {
            int age = 18;

            double pi = 3.1415926;

            float f = 3.14f;

            decimal money = 19.99m;

            bool isTrue = false;

            char c = 'a';

            string str = "hello world";

            Console.WriteLine(age);
            Console.WriteLine(pi);
            Console.WriteLine(f);
            Console.WriteLine(money);
            Console.WriteLine(isTrue);
            Console.WriteLine(c);
            Console.WriteLine(str);

            int a = 3;
            int b = 5;
            int result = a + b;
            Console.WriteLine("{0} + {1} = {2}", a , b, result);
            Console.WriteLine($"{a} + {b} = {result}");

            var i = 0;
        }
    }
}
```

- 在将某变量作为金钱数值使用时，往往使用 decimal 而不是 double 或者 float
  - float 和 double 是二进制浮点数（IEEE 754），无法精确表示 0.1 这样的十进制小数。计算时会产生累积误差

- `Console.WriteLine("{0} + {1} = {2}", a , b, result);` 是 占位符格式
  - 用 {0} {1} {2} 作为占位符，后面按顺序传入参数
- `Console.WriteLine($"{a} + {b} = {result}");` 是 字符串插值
  - 用 $ 前缀，直接在字符串里嵌入变量或表达式
