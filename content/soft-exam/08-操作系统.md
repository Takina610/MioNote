# Linux

**文件与目录操作**
- ls：列出目录内容。常用：ls -l（详细信息）、ls -a（显示隐藏文件）、ls -h（易读大小）。
- cd：切换目录。如 cd ~（到家目录）、cd..（回上级）、cd -（回上一次目录）。
- pwd：显示当前工作目录路径。
- mkdir/rmdir：创建 / 删除目录。mkdir -p 可递归创建多级目录。
- cp：复制文件 / 目录。cp -r 递归复制目录，cp -i 覆盖前提示。
- mv：移动或重命名文件 / 目录。
- rm：删除。rm -r 递归删目录，rm -f 强制删除（谨慎！）。
- touch：创建空文件或更新时间戳。
- cat/tac：正 / 反向显示文件内容；cat -n 带行号；cat file1 file2 > combined 合并文件。
- head/tail：查看文件头部 / 尾部。tail -f 可实时追踪日志更新。
- find：搜索文件。如 find / -name "*.conf"（按名搜）、find . -size +10M（按大小搜）。

**文件权限与属性**
- chmod：修改权限。数字模式（如 chmod 755 file）或符号模式（如 chmod u+x file 加执行权）。
- chown：修改所有者 / 组，格式 chown user:group file。
- umask：设置默认权限掩码（如 umask 022）。

**系统信息与管理**
- top/htop：实时监控 CPU、内存、进程。
- ps：查看进程。ps aux 显示所有进程；ps -ef | grep nginx 查找特定进程。
- kill/pkill：终止进程。kill -9 PID 强制终止；pkill firefox 按进程名杀。
- df：查看磁盘空间。df -h 以易读格式显示。
- du：查看目录 / 文件占用空间。du -sh * 统计当前目录下各文件 / 目录大小。
- free：查看内存使用。free -m 以 MB 为单位。
- uname：显示系统信息。uname -a 显示全部信息（内核、主机名等）。

**网络相关**
- ping：测试网络连通性。如 ping -c 4 google.com 发送 4 个包。
- curl/wget：下载文件。curl -O URL、wget -c URL（断点续传）。
- ssh：远程登录。ssh user@host -p port 指定端口连接。
- scp：安全复制文件。scp file user@remote:/path（上传）。
- netstat/ss：查看网络连接和端口。netstat -tulnp 显示监听的 TCP/UDP 端口及对应进程。
