```csharp
using System;

namespace ConsoleApp1
{
    public delegate void Notify(string message);
    
    class Program
    {
        static void ConsoleNotify(string msg)
        {
            Console.WriteLine($"控制台通知：{msg}");
        }

        static void Main()
        {
            Notify n1 = new Notify(ConsoleNotify);

            Notify n2 = ConsoleNotify;

            n1("hello");
            n2("world");
        }
    }
}
```

C# 的**委托（Delegate）** 是一种类型安全的函数指针，它允许将方法作为参数传递、存储和调用。委托是 C# 实现事件、回调、LINQ 等机制的基础

- 委托是一种引用类型，它封装了一个具有特定签名（参数列表和返回值）的方法。可以把委托看作是一个“方法容器”，里面装的是符合特定签名的方法。
- 调用委托就像调用方法一样：n1("Hello")，实际上会执行它绑定的所有方法。

```csharp
using System;

namespace ConsoleApp1
{
    public delegate void Notify(string message);
    
    class Program
    {
        static void Method1(string msg) => Console.WriteLine($"方法1：{msg}");
        static void Method2(string msg) => Console.WriteLine($"方法2：{msg}");

        static void Main()
        {
            Notify n1 = Method1;

            n1 += Method2;
            n1("hello");

            n1 -= Method1;
            n1("world");
        }
    }
}
```

委托可以绑定多个方法，使用 + 或 += 添加，- 或 -= 移除。调用时会按顺序依次执行所有方法。

>注意：多播委托的返回值是最后一个方法的返回值，中间的返回值会被丢弃。因此多播委托通常用于 void 返回类型
