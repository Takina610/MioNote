```python
a = 10
b = "20"
print(a + int(b))
```
**30（解析：int(b)将字符串 "20" 转为整数 20，与 a 相加得 30）**

```python
def func(a, b=2, c=3):
    return a + b + c
print(func(1, c=5))
```
**答案：8（解析：a=1，b 默认 2，c=5，总和 1+2+5=8）**

```python
nums = [3, 1, 4, 2]
result = sorted(nums, key=lambda x: -x)
print(result)
```
**答案：[4, 3, 2, 1]（解析：lambda x: -x表示按相反数排序，即降序）**

```python
arr = [1, 2, 3, 4, 5]
arr[1:4] = [6]
print(arr)
```
**答案：[1, 6, 5]（解析：切片 1-4（元素 2,3,4）被替换为 [6]）**

```python
lst = [10, 20, 30, 40]
lst.pop(1)
lst.extend([50, 60])
print(lst)
```
**[10, 30, 40, 50, 60]（解析：删除索引 1 的 20，再追加 50、60）**
