# 泛型接受一个参数

```csharp
using System;

namespace ConsoleApp1
{
    class Gen<T>
    {
        public T a, b;

        public Gen(T a, T b)
        {
            this.a = a;
            this.b = b;
        }

        public void show()
        {
            Console.WriteLine($"{a}, {b}");
        }
    }


    class Program
    {
        static void Main()
        {
            Gen<int> gen1 = new(1, 2);
            gen1.show();

            Gen<string> gen2 = new("hello", "world");
            gen2.show();
        }
    }
}
```

# 泛型接受多个参数

```csharp
using System;

namespace ConsoleApp1
{
    class Pair<T1, T2>
    {
        public T1 First { get; set; }
        public T2 Second { get; set; }

        public Pair(T1 first, T2 second)
        {
            First = first;
            Second = second;
        }

        public void show()
        {
            Console.WriteLine($"{First}, {Second}");
        }
    }


    class Program
    {
        static void Main()
        {
            Pair<int, string> pair = new(1, "hello");
            pair.show();
        }
    }
}
```

# 直接在方法使用泛型

```csharp
using System;

namespace ConsoleApp1
{
    class Program
    {
        static void swap<T> (ref T a, ref T b)
        {
            T tmp = a;
            a = b;
            b = tmp;
        }

        static void Main()
        {
            int a = 1, b = 2;
            Console.WriteLine($"a:{a}, b:{b}");
            swap<int>(ref a, ref b);
            Console.WriteLine($"a:{a}, b:{b}");

            string s1 = "hello", s2 = "world";
            Console.WriteLine($"s1:{s1}, s2:{s2}");
            swap(ref s1, ref s2);
            Console.WriteLine($"s1:{s1}, s2:{s2}");
        }
    }
}
```

# 泛型委托

```csharp
public delegate TResult Func<in T, out TResult>(T arg);

// .NET 已内置常用泛型委托
Func<int, int> square = x => x * x;
Action<string> print = s => Console.WriteLine(s);
```

# 泛型约束

**约束让你对类型参数提出要求，从而在泛型代码中调用特定成员。**

```csharp
public class Example<T> where T : class { }         // 引用类型
public class Example<T> where T : struct { }        // 值类型
public class Example<T> where T : new() { }         // 有无参构造函数
public class Example<T> where T : BaseClass { }     // 继承自某基类
public class Example<T> where T : IComparable<T> { }// 实现某接口
public class Example<T, U> where T : U { }          // T 派生自 U
```

| 约束 | 含义 |
|------|------|
| where T : struct | 值类型（不含可空） |
| where T : class | 引用类型 |
| where T : notnull | 不可为 null |
| where T : unmanaged | 非托管类型 |
| where T : new() | 具备公共无参构造 |
| where T : 基类 | 继承自指定基类 |
| where T : 接口 | 实现指定接口 |
| where T : U | 派生自另一类型参数 |

# 组合泛型

```csharp
public class Factory<T> where T : class, IEntity, new()
{
    public T Create() => new T();
}
```

> 注意：new() 必须放在最后；struct 和 class 互斥。
