# List<T> — 动态数组

```csharp
//List<int> ints = new List<int>();
//var ints = new List<int>();
List<int> ints = new();
ints.Add(1);
ints.Add(2);
ints.Add(3);

Console.WriteLine(ints[0]);

foreach(int i in ints)
{
    Console.WriteLine(i);
}

// 创建
List<int> numbers = new List<int>();
List<string> names = new List<string> { "Alice", "Bob" };

// 常用操作
numbers.Add(10);              // 添加
numbers.AddRange(new[] {1,2}); // 批量添加
numbers.Insert(0, 5);         // 指定位置插入
numbers.Remove(10);           // 删除元素
numbers.RemoveAt(0);          // 按索引删除
numbers.Contains(5);          // 是否包含
int count = numbers.Count;    // 元素个数
numbers.Sort();               // 排序
numbers.Clear();              // 清空

// 遍历
foreach (var n in numbers)
    Console.WriteLine(n);

// 索引访问
int first = numbers[0];
```

最常用的集合，相当于可变长度的数组。
特点：内部用数组实现，容量不足时自动扩容（翻倍），随机访问 O(1)，中间插入/删除 O(n)。

# Dictionary<TKey, TValue> — 字典/哈希表

```csharp
var dict = new Dictionary<string, int>();

// 添加
dict.Add("apple", 1);
dict["banana"] = 2;           // 索引器添加/修改

// 访问
int val = dict["apple"];

// 安全访问（推荐）
if (dict.TryGetValue("apple", out int value))
    Console.WriteLine(value);

// 判断/删除
bool has = dict.ContainsKey("apple");
dict.Remove("banana");

// 遍历
foreach (KeyValuePair<string, int> kv in dict)
    Console.WriteLine($"{kv.Key} = {kv.Value}");

// 只遍历键或值
foreach (var key in dict.Keys) { }
foreach (var v in dict.Values) { }
```

键值对集合，通过键快速查找值。
特点：查找、插入、删除平均 O(1)。键必须唯一，不能为 null。

# HashSet<T> — 哈希集合

```csharp
var set = new HashSet<int> { 1, 2, 3 };

set.Add(4);
set.Add(1);            // 重复，返回 false，不会添加
bool has = set.Contains(2);

// 集合运算
var other = new HashSet<int> { 3, 4, 5 };
set.UnionWith(other);        // 并集
set.IntersectWith(other);    // 交集
set.ExceptWith(other);       // 差集

// 去重应用
var list = new List<int> { 1, 1, 2, 3, 3 };
var unique = new HashSet<int>(list);
```

存储不重复的元素，用于去重和集合运算。
特点：元素唯一，查找 O(1)，无序。

# Queue<T> — 队列（先进先出 FIFO）

```csharp
var queue = new Queue<string>();
queue.Enqueue("A");   // 入队
queue.Enqueue("B");

string item = queue.Dequeue();  // 出队 "A"
string peek = queue.Peek();     // 查看队首但不移除
int count = queue.Count;
```
