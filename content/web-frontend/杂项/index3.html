Project 01

MioAI 智能体开发平台

Spring Boot / Spring AI / RAG / Vue3

面向 AI 智能体场景开发的前后端分离平台，支持智能体创建与管理、RAG 知识库构建、MCP 工具接入、 工具调用、流式对话与会话记忆等能力。

Tool Calling Cloudflare R2 Redis OSS
  • 将 AI 对话从一次性字符串返回改造为基于 Spring AI + SSE 的流式输出，本地压测下首字响应时间缩短约 90%。
  • 基于 ExecutorService 线程池对文本切分结果分批并发执行关键词增强与向量入库，使向量化吞吐量提升约 2 至 3 倍。
  • 基于 ReAct 模式构建具备自主规划能力的智能体，支持最多 20 步规划执行，并可协作网页搜索、网页抓取、PDF 生成、资源下载等工具。
  • 设计并实现 RAG 知识库链路，完成文档上传、解析切分、关键词增强、向量入库与相似检索，支持 PDF、Markdown、TXT 等多类型文档。
  • 开发 MCP 工具接入与校验模块，支持 SSE / STDIO 两种模式的配置检测、服务初始化与工具解析，提高平台扩展能力。
Project 02

RemChat 桌面即时通讯软件

Netty / Redis / Redisson / Electron

面向桌面即时通讯场景开发的前后端分离系统，支持好友检索与申请、单聊 / 群聊、富媒体传输、 后台管理、客户端版本更新及 AI 机器人对话，形成了完整的消息业务闭环。

WebSocket MyBatis-Plus SQLite Vue3
  • 基于 Netty WebSocket 自建长连接通信服务，结合心跳检测、连接保活与断线重连，提升聊天场景的实时性与稳定性。
  • 基于 Redisson Topic 设计消息发布订阅链路，将业务消息生产与连接层推送解耦，统一分发私聊、群聊、好友申请、强制下线等多类消息。
  • 使用 Redis 缓存图形验证码、登录 Token、联系人列表、系统配置与用户心跳信息，降低数据库访问压力。
  • 结合 AOP 与自定义注解实现统一登录校验和管理员权限控制，减少重复鉴权逻辑，增强系统维护性。
