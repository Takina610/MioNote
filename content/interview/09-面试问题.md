# HTTP 和 WebSocket 有什么区别

HTTP 和 WebSocket 的区别就在于通信方向；
HTTP 它是单向的，客户端发送一次请求，服务端作出响应；
而 WebSocket 是双向的，双方都可以主动向对方发送消息；
WebSocket 就是基于 HTTP 的，第一次通信时还是 HTTP，通过带上 Upgrade: websocket 头，告诉服务端需要升级协议。

# Spring AI 中，如何去定义一个 Mcp Server

首先得导入一个 Mcp Server 的依赖，可以选择是 Stdio 模式还是 SSE 模式，一般就是 Stdio 模式；
然后编写对应的工具方法，再使用 `@Tool` 注解进行暴露，这个 `description` 属性的值非常重要，会关系到 AI 是否正确调用这个工具；
然后再使用 `@Bean` 注解手动创建 `ToolCallbackProvider`；
再将整个项目打包即可。

Stdio 模式的话 Client 和 Server 必须在同一台机器上，更适合本地开发和单机部署的场景；
SSE 模式是 HTTP 的长连接，不需要在同一台机器上，更适合微服务架构。

# 讲一下 Redis 的哨兵机制

一般是有三个哨兵组成一个集群，然后一个主节点和多个从节点；
第一个功能就是监控主从节点是否存活，哨兵会定时发送心跳包，如果一个哨兵发现一个节点下线了，则会判定为主观下线，此时需要其他两个哨兵确认，如果确认的数量超过总哨兵一半以上，那么就判定为客观下线；
第二个功能就是故障转移，如果下线的是主节点，则会根据选举算法选举出新的主节点；
第三个功能就是通知，选举出新的主节点后，哨兵会通知客户端和其他从节点。
