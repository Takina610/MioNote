```csharp
using System;

namespace ConsoleApp1
{
    class Animal
    {
        public Animal(string name) {
            Name = name;
        }
        public string Name { get; set; }

        public virtual void speak()
        {
            Console.WriteLine($"{Name}在叫");
        }

        public override string ToString()
        {
            return $"name: {Name}";
        }
    }

    class Dog: Animal
    {
        public Dog(string name) : base(name)
        {
        }

        public override void speak()
        {
            Console.WriteLine($"{Name}在汪汪叫");
        }
    }

    class Cat : Animal
    {
        public Cat(string name) : base(name)
        {
        }

        public override void speak()
        {
            Console.WriteLine($"{Name}在喵喵叫");
        }
    }

    class Program
    {
        static void Main()
        {
            Animal dog = new Dog("zs");

            dog.speak();
            Console.WriteLine(dog.ToString());
        }
    }
}
```

**虚方法(Virtual Method)**指的是允许子类重写、并在运行时根据对象的实际类型，决定调用哪个版本的方法

重写方法指的是，*子类为从基类继承的成员方法提供了新的实现*，重写有如下要求:
- **被重写的基方法必须是 virtual/abstract/override**
- **重写时必须使用关键字 override**
- 方法签名、返回值、可访问性必须相同

不能重写非虚方法或static方法
