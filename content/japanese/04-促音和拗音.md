# 日语促音

- 促音在日语中表示停顿一拍（约0.5-1秒）的音节
- 写作小写的“っ”
- 它本身不发音，但它占一个音拍（morae）。它实际上是在为下一个假名的辅音做发音准备时，憋住气流所形成的停顿。

![](./img/Snipaste_2026-08-18_11-06-00.png)

## 如何输入？

不需要单独找 “っ”，直接连续按两次下一个假名的首字母即可。

きって（邮票）：
  - `ki t te`
  - 后面是「て」(t)，所以打两个 t 即可
がっこう（学校）：
  - `ga k ko u`
  - 后面是「こ」(k)，所以打两个 k 即可

==促音后面跟什么辅音，就双击那个辅音的字母==

# 日语拗音

拗音由 い段假名（含浊音、半浊音）加上 小写的「ゃ」「ゅ」「ょ」 组合而成。

- 大假名（12个基础音）：
  - 清音：き (ki)、し (shi)、ち (chi)、に (ni)、ひ (hi)、み (mi)、り (ri)
  - 浊音：ぎ (gi)、じ (ji)、ぢ (ji)、び (bi)、ぴ (pi)
- 小假名（3个）：
  - 小「ゃ」(ya) 、小「ゅ」(yu) 、小「ょ」(yo)

## 发音技巧

口诀：先发 「い」 音，迅速滑向 「や・ゆ・よ」。

例如「きゃ」：先做好发「ki」的口型，但不发完，快速过渡到「ya」，听起来像汉语的「kia」（类似「咖」），但舌尖要顶住下齿。

常见错误：不要把两个音断开（如「ki-ya」），要一口气滑过去，音长为一拍。

## 拗音表

清音拗音（き・し・ち・に・ひ・み・り行）：

| 基础假名 | + ゃ（ya） | + ゅ（yu） | + ょ（yo） |
| -------- | ----------- | ----------- | ----------- |
| き (ki)  | きゃ (kya)  | きゅ (kyu)  | きょ (kyo)  |
| し (shi) | しゃ (sha)  | しゅ (shu)  | しょ (sho)  |
| ち (chi) | ちゃ (cha)  | ちゅ (chu)  | ちょ (cho)  |
| に (ni)  | にゃ (nya)  | にゅ (nyu)  | にょ (nyo)  |
| ひ (hi)  | ひゃ (hya)  | ひゅ (hyu)  | ひょ (hyo)  |
| み (mi)  | みゃ (mya)  | みゅ (myu)  | みょ (myo)  |
| り (ri)  | りゃ (rya)  | りゅ (ryu)  | りょ (ryo)  |

浊音拗音（ぎ・じ・ぢ・び行）：

| 基础假名 | + ゃ（ya） | + ゅ（yu） | + ょ（yo） |
| -------- | ----------- | ----------- | ----------- |
| ぎ (gi)  | ぎゃ (gya)  | ぎゅ (gyu)  | ぎょ (gyo)  |
| じ (ji)  | じゃ (ja)  | じゅ (ju)  | じょ (jo)  |
| ぢ (ji)  | ぢゃ (ja)  | ぢゅ (ju)  | ぢょ (jo)  |
| び (bi)  | びゃ (bya)  | びゅ (byu)  | びょ (byo)  |

半浊音拗音（ぴ行）：

| 基础假名 | + ゃ（ya） | + ゅ（yu） | + ょ（yo） |
| -------- | ----------- | ----------- | ----------- |
| ぴ (pi)  | ぴゃ (pya)  | ぴゅ (pyu)  | ぴょ (pyo)  |

## 如何输入？

比如输入「きゃ」，直接输入 `kya` 即可。（ki + ya → 省略 i，合并为 kya）
