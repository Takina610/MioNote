# ref 和 out

```csharp
using System;

namespace ConsoleApp1
{
    class Program
    {
        static bool MyMethod1(ref int number1, out float result)
        {
            number1 = 100;
            result = 3.14f;

            return true;
        }

        static void Main()
        {
            int number = 1;
            float result;
            
            MyMethod1(ref number, out result);
        }
    }
}
```

- `ref int number1` 和 `out float result` 都是**按引用传递参数**

| 关键字 | 进入方法前 | 进入方法后 | 主要用途 |
|--------|------------|------------|----------|
| `ref`  | 参数**必须已初始化**（有值） | 可以读取，也可以修改 | **输入 + 输出**（带值进来，可能改完带出去） |
| `out`  | 参数**不必初始化**（可以没值） | 在方法返回前**必须赋值** | **纯输出**（只用来把结果带出去） |

- ref —— 双向传递：像是借了原变量的“别名”。
- out —— 单向输出：像是方法额外返回一个值（类似第二个返回值）。

# params

```csharp
using System;

namespace ConsoleApp1
{
    class Program
    {
        static int MyMethod2(params int[] numbers)
        { 
            return numbers[0];
        }

        static void Main()
        {
            MyMethod2(1, 2, 3, 4);
        }
    }
}
```

- params 是 C# 中的一个关键字，用于允许方法接受可变数量的参数。
  - 简单说：它让调用方可以传任意多个同类型的参数，而方法内部把这些参数当作数组来处理。

ps:
- 一个方法只能有一个 params 参数
- params 参数必须是最后一个参数
- 调用时可以传 0 个或多个

# 方法参数赋默认值

```csharp
using System;

namespace ConsoleApp1
{
    class Program
    {
        static int MyMethod3(int a, int b = 0)
        {
            return a + b;
        }

        static void Main()
        {
          // 方式 1：只传必填参数（b 用默认值 0）
          MyMethod3(5);        // 返回 5
          
          // 方式 2：传全部参数（b 用自己的值）
          MyMethod3(5, 3);     // 返回 8
          
          // 方式 3：用命名参数指定（跳过某个可选参数）
          MyMethod3(a: 5);     // 返回 5
          MyMethod3(b: 10, a: 2);  // 返回 12（可以调换顺序）
        }
    }
}
```

- `int b = 0` 叫做可选参数（也叫默认参数）。
