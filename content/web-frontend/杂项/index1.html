03 / Projects

项目经历

MioAI 智能体开发平台

Spring Boot Spring AI RAG Tool Calling MCP Redis Vue3 OSS / R2

面向 AI 智能体场景开发的前后端分离平台，支持智能体创建与管理、RAG 知识库构建、MCP 工具接入、 工具调用、流式对话与会话记忆等功能。

  • 将 AI 对话改造为基于 Spring AI + SSE 的流式输出，本地压测中首字响应时间缩短约 90%。
  • 基于 ExecutorService 线程池并发执行文本切分后的关键词增强与向量入库，本地向量化吞吐提升约 2-3 倍。
  • 基于 ReAct 模式实现具备最多 20 步自主规划能力的 AI 智能体，可协同网页搜索、网页抓取、PDF 生成和资源下载等工具。
  • 设计并实现完整 RAG 链路，支持 PDF、Markdown、TXT 等多类型文档接入与相似检索。
  • 开发 MCP 工具接入与校验模块，支持 SSE / STDIO 两种模式，提高平台扩展性与资源复用能力。

RemChat 桌面即时通讯软件

Spring Boot Netty Redis Redisson MyBatis-Plus MySQL Electron Vue3 SQLite

面向桌面即时通讯场景开发的前后端分离系统，支持用户好友检索与申请、单聊 / 群聊、富媒体传输、后台管理、 客户端版本更新及 AI 机器人对话，完成了从服务端消息分发到桌面端会话展示的完整业务闭环。

  • 基于 Netty WebSocket 自建长连接通信服务，结合心跳检测、连接保活与断线重连，提升消息到达稳定性与交互连续性。
  • 基于 Redisson Topic 设计消息发布订阅链路，支持私聊、群聊、好友申请、强制下线、群成员变更等统一分发。
  • 使用 Redis 缓存验证码、登录 Token、联系人列表、系统配置和用户心跳包信息，降低数据库访问压力。
  • 结合 AOP + 自定义注解实现统一登录校验与管理员权限控制，减少重复鉴权逻辑并提升维护性。
