Case 01

MioAI 智能体开发平台

Spring Boot / Spring AI / RAG / Tool Calling / MCP / Redis / Vue3 / OSS

Agent Platform Knowledge Base Streaming UX

面向 AI 智能体场景开发的前后端分离平台，支持智能体创建与管理、 RAG 知识库构建、MCP 工具接入、工具调用、流式对话与会话记忆。 我把它理解成一套可以自由编排能力的“智能工作台”。

Streaming Response Spring AI + SSE 流式输出，首字响应更快。
Agent Planner ReAct 模式，多步自主规划和工具协作。
RAG Pipeline 上传、解析、切分、向量化、检索一体化。
Cloudflare R2 文档对象存储接入，支撑知识库原始资料管理。
MCP Connector SSE / STDIO 双模式接入、配置检测与解析。
Conversation Memory 多轮对话沉淀上下文，支撑连续交互体验。
  • 流式输出改造： 将 AI 对话从一次性字符串返回升级为基于 Spring AI + SSE 的流式响应， 本地压测中首字响应时间缩短约 90%。
  • 并发向量化优化： 基于 ExecutorService 线程池，对文本切分结果按批次并发执行关键词增强与向量入库， 吞吐量提升约 2-3 倍。
  • 智能体执行链路： 支持网页搜索、网页内容抓取、PDF 生成、资源下载等工具协作， 面向更复杂的问题提供最多 20 步的自主规划能力。
  • 知识增强与扩展性： 完成从文档上传到相似检索的完整 RAG 链路，并支持 MCP 工具自由添加， 让平台更具扩展性与复用价值。
Case 02

RemChat 桌面即时通讯软件

Spring Boot / Netty / Redis / Redisson / MyBatis-Plus / MySQL / Electron / Vue3 / SQLite

Realtime Messaging Desktop IM Pub/Sub

面向桌面即时通讯场景的前后端分离系统，覆盖好友申请、单聊群聊、 富媒体传输、后台管理、客户端版本更新及 AI 机器人对话， 完成从服务端消息分发到桌面端会话展示的完整业务闭环。

Netty Gateway 长连接通信服务，支撑实时消息推送。
Heartbeat Monitor 心跳检测、连接保活与断线重连机制。
Online Presence 在线状态维护，提升聊天连续性与稳定性。
Redisson Topic 发布订阅链路，统一多类消息分发。
Redis Cache Layer 验证码、Token、联系人列表与心跳信息缓存。
AOP Permissions 自定义注解 + AOP，统一登录校验与管理员控制。
  • 长连接实时通信： 基于 Netty WebSocket 自建通信服务，结合心跳检测与断线重连， 实现稳定的消息推送与在线状态维护。
  • 消息分发解耦： 基于 Redisson Topic 设计发布订阅链路，支持私聊、群聊、好友申请、 强制下线、群成员变更等消息统一分发。
  • 缓存与鉴权治理： 使用 Redis 缓存高频状态数据，并通过 AOP + 自定义注解实现统一登录校验， 减少重复逻辑和数据库压力。
  • 桌面端完整闭环： 服务端与桌面端联动完成从消息生产到会话展示的全链路协作， 兼顾稳定性和可扩展性。
