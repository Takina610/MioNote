```csharp
using System;

namespace ConsoleApp1
{
    struct Vector
    {
        double x, y, z;

        public Vector (double x, double y, double z)
        {
            this.x = x;
            this.y = y;
            this.z = z;
        }

        public void getArea()
        {
            Console.WriteLine($"area = {x*y*z}");
        }
    }   

    class Program
    {
        static void Main()
        {
            Vector vector = new Vector(1, 2, 3);
            vector.getArea();
        }
    }
}
```

- **结构体 struct 是一种值类型**，用于封装一组相关的数据成员
- 结构体也可以有字段、属性、方法、构造函数
- 结构体和类最本质的区别是，结构体是值类型
- 使用结构体之前必须初始化全部成员变量
- 给结构体创建了构造方法后，编译器仍然会为该结构体创建一个没有参数的默认构造方法；而则类不会

结构体适合描述一系列轻量、简单的数据，例如:坐标、颜色、范围等简单数值结构

结构体是隐式密封(sealed)的，因此不可作为其他类的基类，但是可以实现接口
