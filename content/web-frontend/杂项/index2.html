01 / Profile

What I Optimize

我做项目时不只盯着“功能完成”，更在意等待感、吞吐量、稳定性和扩展能力是否真的被用户感知到。 下面这四个方向，是我在简历项目里持续打磨的重点。

Speed 让回答更早可见

将 AI 对话改造为基于 Spring AI + SSE 的流式输出，用户无需等待整段结果生成完成， 长回答场景下可以边生成边阅读。

Automation 让复杂任务可自主执行

基于 ReAct 模式构建具备自主规划能力的智能体，支持网页搜索、网页抓取、PDF 生成与资源下载等工具协作。

Throughput 让知识处理更快落地

使用 ExecutorService 线程池并发处理文本切分后的关键词增强与向量入库， 缩短知识库文档向量化耗时。

Reliability 让实时消息稳定送达

基于 Netty WebSocket、心跳检测、连接保活与断线重连机制， 维护即时通讯场景下的在线状态和消息推送连续性。

  • 设计并实现知识库 RAG 链路，完成文档上传到 Cloudflare R2、解析切分、关键词增强、向量化入库与相似检索。
  • 开发 MCP 工具接入与校验模块，支持 SSE / STDIO 两种模式的配置检测、服务初始化与工具解析。
