# CMM

**CMM(Capability Maturity Model，能力成熟度模型)** 是一种用于评估和改进软件开发过程的模型。它将软件开发过程分为五个成熟度级别：

1. **初始级（Initial）**：过程是无序的，成功依赖于个人的努力。
2. **可重复级（Repeatable）**：过程是可重复的，项目管理和过程控制得到加强。
3. **已定义级（Defined）**：过程是标准化的，组织内的所有项目都遵循相同的过程。
4. **已管理级（Quantitatively Managed）**：过程是量化的，使用统计和其他量化技术来管理过程。
5. **优化级（Optimizing）**：过程是持续改进的，组织通过创新和技术进步来提高过程。

CMM的目标是帮助组织识别和改进其软件开发过程，以提高软件质量和开发效率。

### 语句覆盖（最弱）

- **上图语句有："C = C - B"、"B = B + C"、"打印输出 A B C"。**
- **语句覆盖需要将每条语句都执行一次。**

### 判定(分支)覆盖

- **上图有两个判定表达式："A > 0 AND B > 0" 和 "A > 1 OR C > 1" 。**
- **判定覆盖需要将每个判定表达式的真、假都执行一次。**
- **测试用例1：两个判定表达式为真；测试用例2：两个判定表达式为假**

### 条件覆盖

- **上图有三个条件："A > 0"、"B > 0" 和 "A > 1"、"C > 1" 。**
- **条件覆盖需要将每个条件的真、假都执行一次。**

### 判定/条件覆盖

- **判定/条件覆盖需要同时满足判定覆盖和条件覆盖的要求。**

### 条件组合覆盖

- **也就是每个条件的组合都要执行一次：真真、真假、假真、假假...**

### 路径覆盖（最强）

- **需要将所有可能的路径都执行一次。**
- **上图有四条路径："Y -> Y"、"Y -> N"、"N -> Y"、"N -> N"。**

# PERT图

- **甘特图可以表示出任务之间的并行关系，PERT图则不可以**

![](./img/Snipaste_2025-10-21_12-06-54.png)

- **当前节点的最早开始时间** = max(**所有前驱节点的最早完成时间** + **所有前驱节点到该节点的所需时间**)
- **头节点**的**最早开始时间** = **0**
- **当前节点的最晚完成时间** = min(**所有后继节点的最晚开始时间** - **该节点到所有后继节点的所需时间**)
- **尾节点**和**头节点**的 **最晚完成时间** = **最早完成时间**
- 总时差（**松弛时间**） = **最晚完成时间** - **最早完成时间**

## 关键路径

**松弛时间为 0** 的节点成为**关键节点**；**关键节点连起来的路径称为关键路径（包含头尾）**

**关键路径的长度 = 尾节点的最早完成时间/最晚完成时间**
