# 属性和访问器

```csharp
using System;

namespace ConsoleApp1
{
    class Student
    {
        private int age;
        public string Name1 { get; private set; }
        public string Name2 { get; init; }

        public int Age
        {
            get
            {
                return age;
            }

            set
            {
                if (value < 0 || value > 150)
                {
                    throw new ArgumentException();
                }
                age = value;
            }
        }
    }
    class Program
    {
        static void Main()
        {
            Student student = new Student();
            student.Age = 5;
            Console.WriteLine($"{student.Name1} + {student.Name2}");
        }
    }
}
```

- 属性（Property）是方法的语法糖。**一般字段的首字母是小写，而字段对应的属性的首字母则是大写**
  - `public int Age { get; set; }`

- 访问器：
  - `get`（读取器）用于返回属性值。
  - `set`（设置器）用于赋值，有一个隐式参数 `value`。
  - 可以在访问器前加上限定修饰符 `private` 表示该访问器是私有的（只有类内部可以赋值）
  - `init` 是特殊的 `set`，**它仅在对象初始化阶段允许赋值**。
    - 赋值后，该属性变为只读，任何后续代码（包括类外部和内部的其他方法）都无法修改它

# 构造方法

```csharp
using System;

namespace ConsoleApp1
{
    class Student
    {
        public string Name { get; set; }

        public Student(string name)
        {
            Name = name;
        }
    }
    class Program
    {
        static void Main()
        {
            Student student = new Student("zs")
            {
                Name = "lisi"
            };
            Console.WriteLine($"{student.Name}");
        }
    }
}
```

- 对象初始化器（{ }）：
  - 对象初始化器是在构造方法执行完毕之后才执行的。
  - 执行顺序是：`new Student("zs")`（构造方法赋值为 `"zs"`） → 接着执行 `{ Name = "lisi" }`（尝试再赋值为 `"lisi"`）

# const 和 readonly

```csharp
using System;

namespace ConsoleApp1
{
    class Circle
    {
        public const double pi = 3.1415926;

        private readonly double r;

        public Circle (double r)
        {
            this.r = r;
        }

        public double R
        {
            get
            {
                return r;
            }
        }
    }
    class Program
    {
        static void Main()
        {
            Circle circle = new(100);
            Console.WriteLine($"{Circle.pi} + {circle.R}");
        }
    }
}
```

- const（编译时常量）：
  - 编译时确定：值在编译时就固定下来，编译后直接嵌入到IL代码中
  - 隐式 static：属于类型本身，不需要实例就能访问
  - 必须初始化：声明时必须赋值

- readonly（运行时常量）：
  - 运行时确定：值在运行时才确定，可以在构造函数中赋值
  - 灵活初始化：可以在声明时或构造函数中赋值
  - 一旦初始化，就不能再修改
